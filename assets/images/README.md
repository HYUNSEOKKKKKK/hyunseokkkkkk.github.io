# Image assets

- `hero-humanoid.jpg`: optimized generated hero image loaded by the website and Open Graph metadata.
- `favicon.svg`: site favicon and HK monogram placeholder.
- The About portrait currently loads the public GitHub profile avatar directly from GitHub.

To replace the hero, keep the filename or update both the hero image and `og:image` paths in `index.html`. A wide landscape image with the robot on the right works best with the current composition.
