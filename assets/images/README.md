# Image assets

- `robots/toro-footstep-planning.jpg`: TORO hero and featured footstep-planning media.
- `robots/toro-hero.jpg`: portrait-oriented TORO platform photo.
- `robots/marvel-climbing.jpg`: MARVEL wall-traversal experiment sequence.
- `robots/marvel-adaptive-contact.jpg`: adaptive magnetic contact experiment sequence.
- `robots/kaist-lab-platforms.jpg`: KAIST Humanoid and HOUND lab-platform photo.
- `favicon.svg`: site favicon and HK monogram placeholder.
- The About portrait currently loads the public GitHub profile avatar directly from GitHub.

The old `hero-humanoid.*` files are retained only as unused placeholders. To change the live hero, update the TORO image path, preload path, and Open Graph image path in `index.html` together.

Only publish robot media that has been cleared for public use. Keep raw experiment data, internal slides, and unpublished quantitative results outside this repository.
